## 📚 Course Modules (Aligned to Official CLF-C02 Exam Domains)

### Module 1: Cloud Concepts (Exam Weight: 24%)

**Outcome:** Explain cloud benefits, economics, and migration strategies confidently in interviews and the exam.

- What is Cloud Computing? (On-Premises vs Cloud)
- Benefits of AWS Cloud (Elasticity, Agility, Global Reach)
- Cloud Economics: CapEx vs OpEx, Total Cost of Ownership
- Cloud Deployment Models (Public, Private, Hybrid)
- Cloud Service Models (IaaS, PaaS, SaaS)
- AWS Well-Architected Framework (6 Pillars)
- AWS Cloud Adoption Framework (CAF)
- Migration Strategies (The 7 Rs)
- 🧪 **Lab:** Create your AWS Free Tier account safely

### Module 2: Security & Compliance (Exam Weight: 30%)

**Outcome:** Apply the Shared Responsibility Model and secure an AWS account like a professional.

- AWS Shared Responsibility Model
- IAM: Users, Groups, Roles, and Policies
- Multi-Factor Authentication (MFA) and Root User Protection
- AWS Organizations and Service Control Policies
- Encryption at Rest and in Transit (KMS)
- Security Services: WAF, Shield, GuardDuty, Inspector, Trusted Advisor
- Compliance Programs: AWS Artifact, GDPR, ISO, SOC
- 🧪 **Lab:** Set up IAM users, groups, MFA, and a password policy

### Module 3: Cloud Technology & Services (Exam Weight: 34%)

**Outcome:** Choose the right AWS service for any workload — the largest and most practical exam domain.

- **Global Infrastructure:** Regions, Availability Zones, Edge Locations
- **Compute:** EC2 (Instance Types, Pricing Models), Lambda, Elastic Beanstalk, ECS/EKS, Fargate
- **Storage:** S3 (Storage Classes, Lifecycle), EBS, EFS, S3 Glacier, AWS Backup
- **Databases:** RDS, Aurora, DynamoDB, Redshift, ElastiCache
- **Networking:** VPC, Subnets, Security Groups, Route 53, CloudFront, Direct Connect
- **AI/ML Services:** SageMaker, Rekognition, Comprehend, Amazon Q, Bedrock
- **Developer & Deployment:** CloudFormation, CodePipeline, API Gateway
- **Monitoring:** CloudWatch, CloudTrail, AWS Config
- 🧪 **Lab 1:** Launch and connect to an EC2 instance
- 🧪 **Lab 2:** Host a static website on S3
- 🧪 **Lab 3:** Create a serverless function with Lambda

### Module 4: Billing, Pricing & Support (Exam Weight: 12%)

**Outcome:** Estimate, monitor, and reduce AWS bills — the skill employers love most.

- AWS Pricing Models (On-Demand, Reserved, Spot, Savings Plans)
- AWS Free Tier Explained
- AWS Pricing Calculator
- Cost Explorer, Budgets, and Cost Allocation Tags
- Consolidated Billing with Organizations
- AWS Support Plans (Basic, Developer, Business, Enterprise)
- 🧪 **Lab:** Set a billing alarm so you never get surprise bills

### Module 5: Exam Mastery Bootcamp

**Outcome:** Walk into the exam center calm and prepared.

- Exam registration walkthrough (Pearson VUE, online proctoring)
- Question types: Multiple Choice & Multiple Response
- Time management and elimination strategies
- 5 Full-Length Mock Exams with detailed explanations
- Weak-area analysis and revision plan
- 300+ Practice Questions
