## 🎯 Learning Outcomes — What You WILL Be Able to Do

By the end of this course, you will be able to:

1. **Write** clean, professional Python code following industry standards
2. **Solve** real problems with logic: conditions, loops, functions, and data structures
3. **Design** programs with Object-Oriented Programming the way companies expect
4. **Build** complete applications: GUI apps, database apps, and API-connected apps
5. **Automate** boring tasks: files, browsers, emails, and reports
6. **Debug** and fix errors independently — the true mark of a programmer
7. **Present** a GitHub portfolio of 20+ working projects to employers

## 👥 Who This Course Is For

- Absolute beginners choosing their first programming language
- Students preparing for careers in AI, data science, or web development

- Anyone who tried tutorials but never built real projects

## 📚 Course Modules

### Module 1: Python Basics

**Outcome:** Write and run real Python programs.

- Introduction to Python & Installation
- Your First Python Program
- Variables, Data Types & Type Conversion
- Comments, Operators & User Input
- Strings and String Methods
- Randomisation in Python
- Code Blocks and Indentation
- Writing Clean Code from Day One
- Virtual Environments
- 🧪 **3 Practical Projects** (Number Guess Game and more)

### Module 2: Control Flow & Loops

**Outcome:** Make programs that decide and repeat.

- Conditionals (if/elif/else)
- Assert in Python
- For Loops & While Loops
- Break and Continue
- 🧪 **3 Practical Projects**

### Module 3: Functions & Data Structures

**Outcome:** Organize code and data like a professional.

- Functions, Parameters & Return Values
- Types of Functions & Scope
- Lists, Tuples, Dictionaries, Sets
- Slicing & Comprehensions
- Math Module
- 🧪 **3 Practical Projects**

### Module 4: Object-Oriented Programming

**Outcome:** Structure large programs the way real software is built.

- Classes and Objects
- Constructors & Working with Multiple Files
- Encapsulation, Getters and Setters
- Inheritance & the Super Keyword
- Polymorphism, Static, Enum
- Abstract Classes and Interfaces
- 🧪 **3 Practical Projects**

### Module 5: Files, Errors & Modules

**Outcome:** Build programs that survive real-world conditions.

- Exception Handling: Try/Except, Raise, Custom Exceptions
- Reading, Writing and Deleting Files
- Working with CSV Files
- Importing and Using Modules
- Standard Library Highlights
- Date and Time Handling
- 🧪 **Real-World App:** To-Do List Application

### Module 6: GUI Development

**Outcome:** Build desktop apps with windows, buttons, and forms.

- Tkinter Fundamentals
- Layouts, Events and Widgets
- 🧪 **3 Practical Projects** (Income & Expenses Manager App)

### Module 7: Databases

**Outcome:** Store and manage data permanently.

- Connecting to a Database (SQLite/MySQL)
- Executing Queries
- Full CRUD Operations
- 🧪 **3 Practical Projects** (Library Management System)

### Module 8: APIs & Web Automation

**Outcome:** Connect your programs to the internet.

- HTTP Requests in Python
- Working with REST APIs and JSON
- Browser Automation
- 🧪 **3 Practical Projects** (Weather App, Web Scraper)

### Module 9: Debugging & Professional Skills

**Outcome:** Find and fix bugs like a developer, not a beginner.

- Debugging Techniques and Breakpoints
- Reading Error Messages Properly
- Git & GitHub for Your Python Projects
- Code Review Basics
