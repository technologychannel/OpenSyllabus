# 🐧 Linux Administration

> **Linux runs 96% of the world's servers, every Android phone, and all of the cloud. Master it and you master the backbone of modern technology.**

| 📋 | Course Details |
|---|---|
| **Duration** | 8 Weeks (40+ Hours) |
| **Level** | Beginner to Junior SysAdmin |
| **Prerequisites** | Basic computer skills |
| **Format** | Live Classes + Hands-on Server Labs |
| **Certification** | Technology Channel Training Certificate (great preparation for LPI/RHCSA paths) |

---

## 🎯 Learning Outcomes — What You WILL Be Able to Do

By the end of this course, you will be able to:

1. **Navigate and control** any Linux system confidently from the command line
2. **Manage** users, groups, permissions, and software like a system administrator
3. **Automate** repetitive work with Bash scripts and cron jobs
4. **Configure** networking, SSH, and file transfers between servers
5. **Secure and harden** a Linux server against real-world attacks
6. **Deploy** a live web application on your own configured Linux server

## 👥 Who This Course Is For

- Students aiming for DevOps, Cloud, or Cybersecurity careers (Linux is the mandatory first step)
- Developers who want to deploy their own applications
- IT support staff upgrading to server administration
- Windows users switching to professional Linux skills

## 📚 Course Modules

### Module 1: Linux Basics

**Outcome:** Move around a Linux system as comfortably as your own desktop.

- Operating System Overview & Introduction to Linux
- History and Evolution of Linux
- Linux Distributions Overview (Ubuntu, Debian, RHEL, Arch)
- Installing Linux (Dual Boot, Virtual Machine, WSL)
- Basic Linux Commands
- File System Navigation & Linux File System Hierarchy
- Managing Files and Directories
- Text Editors in Linux (Gedit and Vim)
- 🧪 **Lab:** Set up your own Linux machine and complete a command-line challenge

### Module 2: User and Group Management

**Outcome:** Control exactly who can do what on a system.

- Introduction to Users and Groups
- Creating and Managing Users
- Understanding File Ownership
- Working with File Permissions (rwx, chmod, chown)
- Sudo and Root Privileges
- Creating and Managing Groups
- 🧪 **Lab:** Build a multi-user system with correct team permissions

### Module 3: System Administration

**Outcome:** Keep a Linux system healthy, updated, and under control.

- System Startup and Shutdown Processes
- System Monitoring and Process Management (top, htop, ps, kill)
- Managing Software with Package Managers (APT, YUM/DNF)
- Disk Partitioning and Management
- Mounting and Unmounting Filesystems
- Managing Services with Systemd
- Creating Custom Services with Systemctl
- System Logs and Journalctl
- Scheduling Tasks with Cron Jobs
- 🧪 **Lab:** Create your own systemd service and scheduled backup job

### Module 4: Shell Scripting and Automation

**Outcome:** Automate anything you can do by hand.

- Introduction to Bash Shell
- Writing Basic Shell Scripts
- Variables and Control Flow in Bash
- Loops and Functions in Bash
- Operators in Shell Script
- User Input and Command-Line Arguments
- Exit Status and Return Codes
- Managing Environment Variables
- Debugging Shell Scripts
- 🧪 **Lab:** Write an automated server-health-report script

### Module 5: Networking and Security

**Outcome:** Connect, transfer, and troubleshoot across machines securely.

- Basics of Networking in Linux
- Hostname Configuration, IP Addressing and Subnetting
- Configuring Network Interfaces with the `ip` Command
- Secure Shell (SSH): Setup, Keys, and Remote Execution
- File Transfer with SCP and Rsync
- DNS and `resolv.conf` Configuration
- VPN Configuration on Linux
- Network Troubleshooting Tools (ping, traceroute, netstat, tcpdump)
- 🧪 **Lab:** Manage a remote server entirely over SSH

### Module 6: Security and Hardening

**Outcome:** Lock down a server the way production teams do.

- Introduction to System Security
- Understanding the `umask` Concept
- Linux Firewall (UFW / firewalld)
- Overview of AppArmor
- SSH Hardening (keys only, fail2ban, non-standard ports)
- Securing the Linux Server: Checklist Approach
- 🧪 **Lab:** Harden a fresh server and verify with a security audit

### Module 7: Advanced Topics

**Outcome:** Work like a power user.

- Introduction to Tmux (persistent sessions)
- Linux Kernel Overview and Kernel Modules
- Intro to Containers: Why Docker Runs on Linux
